This repository is structured as a professional front-end project: clear setup instructions, deploy-ready configuration, and a maintainable codebase.

## 🛠️ Getting Started

### Prerequisites

- Node.js 18+
- npm / pnpm / yarn
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/starline-complex-website.git

# Navigate into the project
cd starline-complex-website

# Install dependencies
npm install

# Start the development server
npm run dev
