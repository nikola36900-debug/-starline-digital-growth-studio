## Elementor handoff note
The current prototype references images remotely so they are easy to preview. For the final WordPress / Elementor build, upload approved image files to the WordPress Media Library and use those media URLs. Keep the image crops, overlays, and aspect ratios from `styles.css` to reproduce this composition. Confirm the applicable image licence and source before publication.
